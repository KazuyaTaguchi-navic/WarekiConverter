# 西暦⇔和暦（S/H/R）変換ツール

Chrome拡張機能（Manifest V3）。カー用品の適合車種表記など、西暦の年式表記を
和暦（昭和=S／平成=H／令和=R）表記へ変換し、クリップボードにコピーします。

## 主な機能

- ツールバーのアイコンをクリックするとポップアップが開き、開いた時点でページ上に
  選択中のテキストがあれば自動で読み取り、和暦に変換してクリップボードへコピーします。
  （ユーザーは変換後、貼り付けるだけ）
- 変換結果はポップアップ内の入力欄にも表示されるので、目視確認や再コピーができます。
- 元の文字列を手動で入力・貼り付けして「変換」ボタンで変換することも可能です。
- 西暦の表記だけでなく、既に和暦(S/H/R)になっている文字列（例: `R6/6`）を入力・選択
  した場合は自動で判定し、逆に西暦へ変換します（双方向変換）。
- 西暦/和暦早見表を1926年（昭和元年）から表示（現在の年は黄色でハイライト）。
  西暦・和暦（漢字）・S/H/R（略号）・年齢の4列で、セルをクリックするとその値だけ
  クリップボードにコピーされます。

## 対応している入力表記の例

| 入力例 | 変換結果 |
|---|---|
| ２０２４年６月（全角） | R6/6 |
| 2026/11～2027/1 | R8/11～R9/1 |
| 2007年3月～2024年10月 | H19/3～R6/10 |
| 2024年 / 2024 | R6 |
| R6/6（和暦→西暦への逆変換） | 2024/6 |
| H19/3～R6/10（和暦の範囲→西暦） | 2007/3～2024/10 |
| 12/04～21/10（2桁年/2桁月、部品カタログ等） | H24/4～R3/10 |
| 2026.06（ドット区切り） | R8/6 |
| 2026.06-（末尾が区切り記号だけ＝現在も継続中） | R8/6～ |
| ～2024年10月（先頭が区切り記号だけ＝開始日不明） | ～R6/10 |

2桁年（例: `12/04`）は自動車部品カタログでよく使われる表記で、下2桁だけの西暦を
表します。00〜49を2000年代、50〜99を1900年代として展開します（1950〜2049年に対応）。

全角数字・全角スラッシュ、"年/月"表記、"/"区切り表記、"."区切り表記、範囲区切り
（～、~、〜、-など任意の記号）が混在していても、文字列中から日付らしき箇所を
自動抽出して変換します。範囲の場合は最初に見つかった日付と最後に見つかった日付を
「～」で結合します。日付が1件だけ見つかり、その前後に区切り記号だけがある場合は
「開始日のみ（〜現在）」「終了日のみ（開始日不明）」の片側範囲とみなし、
変換結果にも「～」を残します。

## 元号境界の扱いについて（注意事項）

日付に「日」まで含まれていない場合、以下の年は前後の元号どちらにも該当しうるため、
下記の仮定で決定しています（実際の車検証の日付が分かる場合は変換後の結果を手動で
修正してください）。

- **1926年**: 月不明時は昭和元年（S1）として扱う（昭和は1926/12/25開始）
- **1989年**: 1月かつ日まで分かれば1〜7日はS64・8日以降はH1。月のみ／年のみの場合は
  平成元年（H1）として扱う（昭和は1989/1/7まで）
- **2019年**: 4月以前はH31、5月以降はR1（平成は2019/4/30まで、この境界は月単位で確定）

## インストール方法（開発者モードで読み込み）

1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をONにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリックし、この
   `WarekiConverter` フォルダを選択する
4. ツールバーにアイコンが追加されるので、ページ内で年式らしき文字列を選択してから
   アイコンをクリックすると自動的に変換・コピーされます

## 開発

```bash
npm test   # convert.js の変換ロジックの単体テストを実行
```

アイコン（`icons/`配下のPNG）は `scripts/generate-icons.cjs` で生成しています。
好きなアイコンに差し替えたい場合は `icons/icon16.png` `icons/icon48.png`
`icons/icon128.png` を直接置き換えてください。

## ファイル構成

- `manifest.json` — 拡張機能の定義（Manifest V3）
- `popup.html` / `popup.css` / `popup.js` — アイコンクリック時のポップアップUI
- `convert.js` — 西暦→和暦の変換ロジック本体（純粋関数、テスト対象）
- `tests/convert.test.mjs` — 変換ロジックの単体テスト
- `scripts/generate-icons.cjs` — アイコンPNG生成スクリプト
